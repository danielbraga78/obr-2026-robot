# ATENÇÃO: numpy e opencv NÃO entram aqui de propósito.
#
# No Raspberry Pi o venv precisa de --system-site-packages para enxergar o
# picamera2, e nesse modo os pacotes do pip têm prioridade sobre os do sistema.
# Instalar numpy pelo pip mascara o numpy do sistema e quebra a ABI das
# bibliotecas compiladas contra ele (simplejpeg, libcamera), com o erro
# "ValueError: numpy.dtype size changed" ao importar picamera2.
#
# No Raspberry Pi, instale numpy e opencv pelo sistema:
#   sudo apt install -y python3-picamera2 python3-opencv python3-numpy
# O python3-opencv do apt ainda tem a vantagem de vir com GUI e GStreamer,
# que os wheels do pip não têm.
#
# Fora do Raspberry Pi (desenvolvimento, testes em desktop):
#   pip install -r requirements-dev.txt
